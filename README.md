# Chicken Business System

A beginner-friendly chicken and egg ordering and sales management system.

The project is organized into a React frontend and a Flask backend. SQLite will
be used as the initial database. Application logic will be added in later
development stages.

## Project areas

- `frontend/` — React user interface.
- `backend/` — Flask application and backend tests.
- `docs/` — Project documentation and design notes.
- `PROJECT_REQUIREMENTS.txt` — Project requirements.
